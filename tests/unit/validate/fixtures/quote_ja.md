# クイルストーン 2.0 のリリースノート

クイルストーン 2.0 では、クエリプランナーを全面的に書き直した。幅の広いテーブルを結合するときに、中間バッファをヒープに確保しなくなったため、分析系の処理の中央値の待ち時間が約3分の1に減り、メモリの使用量は変わらなかった。

- 新しいプランナーは既定で有効になる。もう1つ先のリリースまでは、環境変数でこれまでのプランナーに戻せる。
- プリペアドステートメントを接続ごとにキャッシュするようになり、アクセスが集中したときに同じ問い合わせを何度も計画し直す無駄がなくなった。
- コマンドラインツールに説明用のフラグを足した。選ばれた計画と、各段階の見積もりコストを表示できる。

リリース候補の期間に不具合を報告してくれたみなさんに感謝する。提供してもらった記録のおかげで、正式版の前に遅い経路を直せた。
